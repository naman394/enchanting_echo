# VyaktAI - Trust & Safety Data Engine

VyaktAI is a next-generation **Data Engine platform for Trust & Safety**, designed to power AI models with high-quality, human-verified datasets for the Indian market.

We specialize in **Social Media Content Moderation**, helping platforms detect hate speech, NSFW content, and toxic audio in code-mixed languages (Hinglish, Tamil, Telugu, etc.).

## 🚀 Features

-   **Visual Moderation**: Real-time detection of violence, gore, and policy violations.
-   **Language Safety**: Advanced NLP for parsing code-mixed Indic toxicity and hate speech.
-   **Audio Intelligence**: Toxicity detection in voice chats and live streams.
-   **Enterprise-Grade Quality**: Multi-stage verification workflows ensuring >95% accuracy.

## 🛠️ Tech Stack

-   **Framework**: Next.js 15 (App Router)
-   **Styling**: Tailwind CSS v4
-   **Animations**: Framer Motion
-   **Icons**: Lucide React
-   **Font**: Inter (Body) & Outfit (Display)

## ⚡ Getting Started

1.  Clone the repository:
    ```bash
    git clone https://github.com/yourusername/vyaktai-platform.git
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Run the development server:
    ```bash
    npm run dev
    ```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
